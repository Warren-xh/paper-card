# 文献卡片 Paper Cards

**中文** | [English](README.en.md)

一个放在 GitHub Pages 上的个人学习网站：读论文写**论文卡片**，写代码、跑实验写**实操记录**，看课程写**课程笔记**，再用**思维导图**把它们串起来。不需要服务器、不需要数据库、不用花钱；在任何设备上输入密码就能写，保存后网站约 1 分钟自动更新。

当前版本：**v4.1**（[版本记录](CHANGELOG.md)）· 界面默认中文，可切换英文 · [MIT 许可证](LICENSE)。

> **注意**：本仓库根目录下的 `data/`、`papers/`、`code/`、`materials/`、`uploads/` 是作者自己的内容。想部署自己的网站，请下载下面的**发布包**，不要直接复制或 Fork 整个仓库。

## 能做什么

顶栏的「**文献 | 实操 | 课程 | 导图**」切换四种模式。每个模式的列表都能**搜索**和**排序**（排序选择会被记住）。

**文献：论文卡片**

- 一篇论文一张卡片。编辑分四个阶段：
  1. **读之前**：一行写下为什么读。
  2. **边读边记**：只打标记，有 `?` 没看懂、`!` 关键结论、`★` 可以借鉴、`×` 有问题、`✎` 普通笔记五种；页码可以用 ＋/− 调整；觉得没解决的勾「待解决」。
  3. **初步解决**：给勾了「待解决」的标记写答案。
  4. **合上论文再写**：一句话、痛点、核心想法、怎么证明的、疑问 / 局限、和我有什么关系、关联其他卡片。
- 可以上传论文 PDF，卡片页可下载；可以插图、写公式（`$…$`）、加粗斜体。
- **回忆模式**：卡片内容先模糊遮住，自己回想后逐栏揭晓。
- **间隔回顾**：卡片标成「读完」后，第二天开始提醒；想起来了，间隔按 1 → 7 → 30 → 90 → 180 天拉长。

**实操：实操记录**

- 记录写代码、跑实验、做练习的过程：开始前写目标；过程中随手记（`▶` 操作、`✗` 报错、`✓` 成功、`?` 疑问、`✎` 笔记，每条自动带时间）；做完写结论、问题与解决、关键代码、结果、下次要做。
- 可以上传代码文件或整个文件夹，网页上直接查看和下载；自动跳过 `.env`、密钥、`node_modules` 等。
- 可以关联论文卡片，卡片页会显示「相关实操记录」。

**课程：课程笔记**

- 一门课程包含多节课：写讲师 / 平台、链接、为什么学；可以一次批量添加全部课时（每行一课），之后随时调整顺序。
- 课程页列出「第 1 课、第 2 课……」，点任意一课进去：
  - **笔记**：要点、公式、代码、截图都写在这里（截图可以直接 Ctrl+V 粘贴）。
  - **课件与资料**：上传课件 PDF、PPT、讲义、图片等（也可以直接拖进来），课时页上可以打开、下载，图片显示成缩略图。
  - **边看边记**（可选）：打**带视频时间点**的标记（`?` 没听懂、`!` 重点、`★` 可以用、`✎` 笔记），没听懂的勾「待解决」，看完后写答案；再写这一课的一句话。
- 课程页有进度条和课时列表，点圆圈就能标记「看完了」；「继续：下一课」直接跳到还没看的那一课。学完后写学完总结。

**导图：思维导图**

- 分支可以是文字、论文卡片、实操记录或课程，四种外观不同，一眼能分清。
- **浏览模式**：拖动画布、缩放、折叠；点论文、实操或课程分支直接打开；「在图中查找」高亮命中的分支，回车逐个跳过去。
- **编辑模式**：加分支、改颜色、写备注、拖动分支移动位置，支持撤销和快捷键。

**图片**：所有模块的笔记框都有「插入图片」按钮，也可以直接 **Ctrl+V 粘贴截图**或把图片拖进来；一行的标记、过程记录里也能粘贴。图片在浏览器里压缩后随保存一起上传。

**其他**：阅读标记、过程记录这类一行输入框会随内容自动变高，长文字不会被挡住；草稿自动存在本机；每次保存都是一次 Git 提交，改错了能从历史里找回；可以一键导出全部内容（Markdown / JSON）；明暗主题；手机上也能用。

## 部署自己的网站（约 10 分钟，不用装软件）

需要：一个 GitHub 账号（没有的话到 <https://github.com/signup> 免费注册）。全程在网页上操作。

### 第 1 步：下载并解压

点上面的「下载最新发布包」，解压后得到一个 `paper-card` 文件夹，里面有 `index.html`、`css/`、`js/`、`data/` 等。

### 第 2 步：新建仓库

1. 打开 <https://github.com/new>。
2. **Repository name** 填一个名字，比如 `paper-card`。网址会是 `https://你的用户名.github.io/这个名字/`。
3. 选 **Public**（免费账号只有公开仓库才能开 GitHub Pages）。
4. 下面的选项（README、.gitignore、license）**都不要勾**。
5. 点 **Create repository**。

### 第 3 步：上传文件

1. 在新仓库页面，点 **uploading an existing file** 这个链接（在「Quick setup」那一段里）。
2. 打开 `paper-card` 文件夹，**选中里面的全部文件和文件夹**（不是 `paper-card` 文件夹本身），拖进网页。
   - Mac 默认不显示以 `.` 开头的隐藏文件（如 `.nojekyll`）。在访达里按 `⌘ + Shift + .` 可以显示。不传它们网站也能用。
3. 等上传完，点页面底部的 **Commit changes**。

上传后，仓库首页应该能直接看到 `index.html`、`css`、`js`、`data` 等，而不是一个 `paper-card` 文件夹。如果多了一层文件夹，把仓库删掉重来，这次拖的是文件夹**里面**的内容。

### 第 4 步：开启 GitHub Pages

1. 在仓库里点 **Settings**（齿轮图标）→ 左侧 **Pages**。
2. **Source** 选 **Deploy from a branch**。
3. **Branch** 选 **main**，文件夹选 **/ (root)**，点 **Save**。
4. 等 1～2 分钟，刷新这个页面，顶部会出现 **Your site is live at …**，那就是你的网址。

### 第 5 步：（可选）改仓库名设置

打开仓库里的 `data/site.json`，点铅笔图标编辑，把 `"repo"` 改成 `你的用户名/仓库名`，点 **Commit changes**。网站部署在 `github.io` 上时会自动识别仓库，这一步主要是为了本地预览；改了更保险。

### 第 6 步：打开网站，做第一次设置

打开你的网址，按下一节的步骤做一次「第一次设置」，之后就能开始写了。

## 第一次设置：令牌和密码

网站是静态页面，要往仓库里写内容需要 GitHub 授权。这一步只做一次。

1. 打开你的网站，点右上角 **设置** → **开始设置**（或者点「登录编辑」，按提示进入）。
2. 点 **打开 GitHub 令牌页面**。会打开 GitHub 的「New fine-grained personal access token」页面，名称、说明、有效期（一年）和权限都已经预填好。如果要求登录 GitHub，就先登录。
3. 在 GitHub 页面上检查这几项：
   - **Resource owner**：你自己的账号。
   - **Expiration**：最长一年（到期后在网站「设置 → 修改密码 / 更换令牌」里换新的）。
   - **Repository access**：选 **Only select repositories**，再在下拉框里**只选**你刚建的那个仓库。
   - **Permissions → Repository permissions → Contents**：选 **Read and write**（Metadata 会自动变成 Read-only，这是正常的）。
4. 拉到页面底部，点 **Generate token**，再确认一次。
5. 复制生成的令牌（以 `github_pat_` 开头）。**它只显示这一次**，复制好再离开页面。
6. 回到网站，把令牌粘贴到「GitHub 令牌」框里。
7. 设一个密码（至少 8 位，字母加数字，不要和其他账号共用），再输一次。
8. 点 **完成设置**。看到「设置完成」就可以写第一张卡片了。

之后在任何设备（包括手机）上打开网址，点「登录编辑」输入密码就能写；勾选「在这台设备上记住我 30 天」可以少输几次。

## 会用命令行？用 git 部署

```bash
# 下载并解压发布包
curl -L -o paper-card.zip https://github.com/Warren-xh/paper-card/releases/latest/download/paper-card.zip
unzip paper-card.zip && cd paper-card

# 推到你在 GitHub 上新建的空仓库
git init -b main
git add -A
git commit -m "文献卡片 v4.1"
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

然后照「第 4 步：开启 GitHub Pages」和「第一次设置」继续。

## 更新到新版本

你的内容都在 `data/`、`papers/`、`code/`、`materials/`、`uploads/` 里，更新时**只换代码，不动这些文件夹**：

1. 下载新版本的发布包并解压。
2. 在你的仓库里上传并覆盖这些：`index.html`、`css/`、`js/`、`scripts/`、`tests/`、`package.json`、`README.md`、`README.en.md`、`CHANGELOG.md`、`LICENSE`。
3. **不要**上传发布包里的 `data/` 文件夹（里面是空白数据，会覆盖你的索引）。

用 git 的话：把新版本的上述文件复制进你的仓库目录，提交并推送即可。

## 常见问题

**网址打开是 404。**
刚开启 Pages 要等 1～3 分钟。再检查：Settings → Pages 里 Branch 是 `main` 和 `/ (root)`；仓库首页能直接看到 `index.html`（没有多一层文件夹）。

**保存时提示「GitHub 拒绝了请求」或「找不到仓库」。**
令牌没有授权这个仓库，或者 Contents 不是 Read and write。到「设置 → 修改密码 / 更换令牌」，按上面的步骤重新生成一个令牌换上。

**令牌过期了。**
在 GitHub 重新生成一个，到网站「设置 → 修改密码 / 更换令牌」，输入现在的密码，粘贴新令牌保存。

**忘了密码。**
密码没法找回。重新生成一个令牌，到「设置 → 第一次设置」重新设置即可，内容不受影响。

**可以用私有仓库吗？**
免费账号的 GitHub Pages 只能用于公开仓库。仓库公开意味着别人能看到你的卡片、上传的 PDF 和代码；加密的只是令牌。不想公开的内容别写进去，付费期刊的 PDF 请留意版权。

**刚保存的内容别的设备上看不到。**
网站更新需要约 1 分钟，稍后刷新即可。

**怎么换成英文界面？**
点顶栏的「EN」，或者在「设置 → 界面语言」里选 English（手机上在设置页里选）。只有界面会翻译，你写的内容保持原样。

**怎么备份？**
每次保存都是一次 Git 提交，GitHub 上有完整历史。也可以在「设置 → 备份」一键下载全部内容（Markdown 或 JSON）。

## 密码是怎么工作的

- 你的 GitHub 令牌在浏览器里用你的密码加密（PBKDF2 60 万次 + AES-256-GCM），只把加密结果存成 `data/vault.json`。
- 密码本身不会发送或保存到任何地方。在任何设备上输入密码，浏览器在本地解开令牌，直接把修改提交到你的仓库。
- 令牌只授权这一个仓库，碰不到你的其他仓库和账号。万一泄露，到 GitHub 删除令牌，再重新设置即可。
- 解锁默认只在当前标签页有效，闲置 30 分钟自动锁定；勾选「记住我 30 天」则在这台设备上保持 30 天。

## 数据存在哪里

| 路径 | 内容 |
| --- | --- |
| `data/cards/<id>.json` | 一篇论文一张卡片 |
| `data/index.json` | 卡片摘要，用于首页、搜索和回顾 |
| `data/logs/<id>.json`、`data/logs-index.json` | 实操记录和摘要 |
| `data/courses/<id>.json`、`data/courses-index.json` | 课程（含全部课时笔记）和摘要 |
| `data/maps/<id>.json`、`data/maps-index.json` | 思维导图和摘要 |
| `data/site.json` | 网站标题、仓库名等设置 |
| `data/vault.json` | 加密后的编辑授权（第一次设置后才有） |
| `papers/` | 上传的论文 PDF |
| `code/<记录编号>/` | 实操记录里上传的代码 |
| `materials/<课程编号>/<课时编号>/` | 课程里每一课上传的课件和资料 |
| `uploads/` | 插入的图片 |

## 仓库里有什么

| 路径 | 说明 |
| --- | --- |
| `index.html`、`css/`、`js/` | 网站本身（纯静态，无构建步骤、无依赖） |

## 本地开发

需要 Node.js 18 以上，没有任何依赖。

```bash
npm test              # 单元测试
npm run dev           # 预览 http://127.0.0.1:4180
npm run mock          # 带模拟 GitHub 的预览：http://127.0.0.1:4180/?mock
npm run reindex       # 手动改过 data/cards/ 后重建 data/index.json
```

模拟模式可以完整试用第一次设置、发布、上传、导图等（令牌随便填一个 `github_pat_` 开头、足够长的字符串）。所有修改只存在内存里，关掉服务就消失，不会碰到真实仓库。

主要代码：

| 文件 | 作用 |
| --- | --- |
| `js/app.mjs` | 路由、论文卡片的页面、设置、第一次设置 |
| `js/model.mjs` | 卡片数据、回顾间隔、搜索、导出 |
| `js/lab.mjs`、`js/lab-views.mjs` | 实操记录 |
| `js/course.mjs`、`js/course-views.mjs` | 课程笔记 |
| `js/mindmap.mjs`、`js/map-views.mjs` | 思维导图的数据、自动排版和页面 |
| `js/i18n.mjs` | 界面语言（中文 / English） |
| `js/github.mjs` | 通过 Git Data API 一次提交多个文件，冲突自动重试 |
| `js/vault.mjs` | 令牌加密 |
| `js/markdown.mjs` | 安全的 Markdown 渲染 |
