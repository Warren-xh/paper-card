每个压缩包都是一份完整的网站：全部代码加一套空白数据，**不含**任何人的内容和密码，解压后就能部署成一个全新的网站。仓库里还有同名标签（`v1.0`、`v2.0`、`v3.1`、`v4.0`、`v4.2`、`v4.3`），记录的是保存当天的整个仓库。

Each package is a complete site — all the code plus an empty set of data, **without** anyone's content or password — ready to deploy as a fresh site. Tags with the same names (`v1.0`, `v2.0`, `v3.1`, `v4.0`, `v4.2`, `v4.3`) record the whole repository on each date.

**部署步骤见 [README.md](../README.md#部署自己的网站约-10-分钟不用装软件)。**
**For deployment steps see [README.en.md](../README.en.md#deploy-your-own-site-about-10-minutes-nothing-to-install).**

旧版本的部署步骤与 v4.3 相同；更新已有网站时只覆盖代码文件，不要覆盖 `data/`、`uploads/`、`papers/`、`code/`、`materials/`。
Older versions deploy the same way. When updating an existing site, replace only the code; never overwrite `data/`, `uploads/`, `papers/`, `code/` or `materials/`.
